# Boutique studio niches (breakdown)

**Date.** Sep 18, 2026
**Parent category.** One OS: class packs, memberships, waitlists, instructors, client booking.

Ads say **pilates**. Product also does Lagree and barre on day one.

## Core (v1)

**Reformer pilates**  
Machines in rows. Client picks a **spot**. Packs + memberships + privates/duets. Independent studios only. First 20 customers.

**Lagree / Megaformer**  
Same as pilates, Megaformer instead of reformer. Spot booking matters more. Same app.

**Barre (independent)**  
Usually room headcount, not machine #12. Still packs and waitlists. Pure Barre = franchise, skip.

## Same app, later types

**Hot yoga / yoga sculpt**  
Mats + room cap. Target studios with a lease and 4+ instructors, not church-basement solo teachers on Acuity $20.

**Boutique cycling**  
Bikes with spot numbers. Independent only. Not CycleBar.

**Boxing / kickboxing, HIIT / bootcamp**  
Same class engine. Don’t lead marketing with these.

**Stretch / mobility (independent)**  
Often 1:1 tables plus classes. StretchLab = franchise.

## Cousin (new booking math)

**Recovery / plunge / sauna / contrast**  
Rooms and beds by the hour. Memberships for off-peak. Instagram-native. Add as a type, not company two.

**Small PT gyms**  
Trainer calendar + packs. Low willingness unless 5+ trainers.

**Pilates + cash-pay PT hybrid**  
Keep PT as privates. Do not become an EMR.

## Not this product

| Niche | Why |
|-------|-----|
| CrossFit / Hyrox | WODs, drop-ins, Zen Planner |
| BJJ / martial arts | Belts, kids contracts, Kicksite |
| Kids dance / cheer | Jackrabbit |
| Climbing | Rock Gym Pro |
| Big-box gym | ABC Fitness |
| Med spa in the same plaza | Boulevard / HIPAA |

## Franchises (do not sell)

Club Pilates, Solidcore, Pure Barre, StretchLab, F45, Orangetheory, CycleBar.
